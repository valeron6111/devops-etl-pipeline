# DevOps ETL Pipeline with Airflow, DBT, and Grafana

Этот репозиторий демонстрирует ETL-пайплайн с использованием **Airflow**, **DBT** и **Grafana** для преобразования и мониторинга данных.

## Архитектура
1. **ETL процесс**: Пайплайн извлекает данные из PostgreSQL, обрабатывает их и загружает в таблицы стадии.
2. **Airflow**: Оркестрация ETL процесса и преобразований DBT.
3. **DBT**: Преобразует сырые данные в полезные таблицы.
4. **Grafana**: Визуализирует метрики PostgreSQL.
