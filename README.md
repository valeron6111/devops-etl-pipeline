# DevOps ETL Pipeline with Airflow, DBT, and Grafana

Этот репозиторий демонстрирует ETL-пайплайн с использованием **Airflow**, **DBT** и **Grafana** для извлечения, трансформации и загрузки (ETL) данных, а также для мониторинга и визуализации данных.

## Архитектура
1. **ETL процесс**: Пайплайн извлекает данные из PostgreSQL, обрабатывает их и загружает в таблицы стадии.
2. **Airflow**: Оркестрация ETL процесса и запуска преобразований с помощью DBT.
3. **DBT**: Преобразует сырые данные в полезные таблицы и улучшает их для дальнейшего анализа.
4. **Grafana**: Визуализирует метрики и статистику из PostgreSQL для мониторинга производительности и состояния данных.
